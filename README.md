# Thesis project presentation: Medical Device predicting Multiple Sclerosis worsening

For my Bachelor's thesis in Artificial Intelligence at the Universities of Pavia, Milan and Milano-Bicocca, I designed and developed an AI-based clinical decision support prototype that uses patient data to predict worsening in multiple sclerosis.
The project includes an interactive interface designed for healthcare professionals to enter patient information and obtain predictions in real time. Each prediction is accompanied by an explanation and reliability measures, helping users understand the result and assess how much to trust it.
